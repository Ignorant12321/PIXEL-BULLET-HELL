# 快速上手

这份文档面向第一次打开项目的人：如何运行游戏、如何操作、如何验证项目是否正常。

## 项目是什么

`像素星舰` 是一个纯静态的像素风横版弹幕防守小游戏。玩家选择一艘星舰，在右侧基地前抵御两幕敌潮，通过商店和军械库强化武器，最终击破 Boss。

项目使用浏览器原生 ES Modules，不需要打包工具。主要代码在 `src/js/`，样式在 `src/styles/`，入口页面是 `index.html`。

## 环境要求

需要本机有：

- 一个现代浏览器
- Node.js，用于运行测试
- Python，用于 `npm run serve` 启动静态服务器

如果没有 Python，也可以用任何静态服务器打开项目目录，只要能通过 `http://localhost` 访问 `index.html` 即可。

## 启动游戏

在项目根目录运行：

```bash
npm run serve
```

默认会启动：

```text
http://localhost:8000/
```

然后在浏览器打开这个地址。

不推荐直接双击 `index.html`。浏览器对 `file://` 下的 ES Modules 支持不稳定，可能导致模块加载失败。

## 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | `WASD` 或方向键 |
| 慢速移动 | `Shift` |
| 开始 / 继续 | `Space` 或 `Enter` |
| 暂停 | `P` |
| 歼灭弹 | `X` |
| 商店 / 军械库 | `B` |
| 图鉴 | `C` |

触屏设备会显示屏幕方向键、慢速键和歼灭弹按钮。

## 基本玩法

1. 在开局界面选择星舰。
2. 开始后守住右侧基地，不要让敌人突破。
3. 击败敌人获得分数和金币。
4. 在波次间进入商店或军械库升级。
5. 合理使用歼灭弹和掉落道具处理高压波次。
6. 通关两幕并击败最终 Boss。

## 调试入口

游戏启动后会在浏览器控制台暴露：

```js
window.pixelStarship
```

常用对象：

```js
window.pixelStarship.game
window.pixelStarship.ui
```

可以用它查看当前状态：

```js
window.pixelStarship.game.view()
```

如果改了数值或 UI，建议边玩边观察 `game.view()`，确认金币、波次、生命、武器和状态是否符合预期。

## 运行测试

在项目根目录运行：

```bash
npm test
```

测试会覆盖波次数据、星舰数据、军械库、商店、HUD、敌人能力和核心运行工具。修改数据或逻辑后都建议跑一遍。

## 常见问题

### 页面空白

优先确认是否通过 `npm run serve` 访问，而不是直接用 `file://` 打开。

### 改了 JS 但浏览器没变化

刷新页面。如果仍然没变化，打开浏览器开发者工具，检查 Console 是否有模块路径错误或语法错误。

### 新增数据没有出现

大多数数据文件都需要在对应的 `index.js` 中注册。比如新增星舰后，还要更新：

```text
src/js/data/starships/index.js
```

### 改波次后测试失败

先看：

```text
docs/wave-system.md
```

波次文件现在推荐用 `phases`，并通过 `defineWave()` 自动生成兼容用的 `entries`。
